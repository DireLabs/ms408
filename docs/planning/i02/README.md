## The standing correction i02 must honor

The i01 critique log established that a positive finding requires:
1. **Blind nulls** — any null model used as a "meaningless" baseline must be
   adversarially optimized toward the discriminating statistic, blind to the real
   target, not tuned by the team.
2. **Confidence intervals** — no "0.31 vs X" comparison without the estimator's CI
   at the real corpus length.
3. **Power reported** — no null result without a power curve / minimum detectable
   effect.
4. **Disattenuation** — associations on noisy annotations reported both raw and
   disattenuated for measurement error.
5. **Symmetric evidence accounting** — nulls treated identically across hypotheses;
   no crediting a hypothesis for being unfalsifiable.
