# i07 — Characterising the surviving class: positional/template generation

**Inherits** all locks L1–L37; the standing clean-context refutation rule; the firewall
(L3); L7 absolute (no decipherment / meaning / real-taxon claim without an independent
anchor). Continues the experiment ledger as **E21–E22**.

## Where i06 left us

i06 closed the cryptanalytic direction with a hardened NEGATIVE (E19/E19b/E20): the VMS
is **not a cipher of real prose**. It uniquely combines (a) low character entropy
(h2 ≈ 2.0), (b) retained *block-scale* word-order information (ΔI ≈ 0.16–0.20, above the
shuffle floor), and (c) weak word-level syntax (fc_z/wc_z near zero or negative). No
word-order-preserving cipher reaches (c) — it inherits the plaintext's strong syntax,
universally across Romance/Germanic/Semitic — and no transposition cipher keeps (b). The
resolution the data points to (from the block/section structure of ΔI, E1/E2): the VMS's
retained order information is **positional/template** structure, not linguistic word
order → a template-driven / positional *generative* system.

## The i07 question — the positive complement

**Can a template-driven / positional generative mechanism, NOT tuned to Voynich,
reproduce the VMS's full joint signature — low h2, retained block-scale ΔI, AND weak
word-syntax — simultaneously? And which generative ingredients are *necessary* for each
property?**

This is the dual of the i06 exclusion. i06 showed ciphers of real prose *cannot* produce
weak syntax while keeping ΔI. i07 asks whether generation *can*, and — more valuably —
turns the hand-wave "template/positional generation" into a **specified, falsifiable
mechanism with an identified ingredient→property map**.

## The circularity firewall (the load-bearing discipline of i07)

The self-citation (Timm–Schinner) generator already matches the VMS signature — but it is
**Voynich-tuned by construction**, so its match is worthless as evidence (this is exactly
why E19's first-pass "favours generation" positive was rejected as circular). i07's entire
value depends on not repeating that mistake. Therefore:

1. **No parameter of the generator may be fit to, or read from, a VMS statistic.** All
   inventory sizes, block lengths, and frequency exponents are set a priori or derived
   from a **non-Voynich real source** (Latin structure), and documented as chosen blind
   to the VMS numbers. → **[D-item i07-a — surfaced to Tim; see DECISIONS.]** Default
   taken (least-committal): fixed a-priori constants + a coarse grid *landscape* (E22),
   never a single tuned point; report where the family lands rather than fitting to VMS.
2. **The deliverable is the ingredient→property map and the honest mismatch list, NOT a
   distance-to-VMS.** "The generator hits the VMS band" is, alone, near-vacuous
   (self-citation already does). The informative results are: *which* ingredient is
   necessary for *which* VMS property (ablation), and *which* axes the mechanism still
   misses (e.g. ΔI scale, TTR, word length).
3. **Sufficiency ≠ identification (L7).** The strongest claim i07 can earn is that the
   positional/template *class* is a viable positive account of the signature (grade B
   ceiling). It never shows the VMS *is* this generator; E9's underdetermination stands.
