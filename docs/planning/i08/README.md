# i08 — Adding the reuse mechanism the i07 misses demand

**Inherits** all locks L1–L37; the standing clean-context refutation rule; the firewall
(L3); L7 absolute. Continues the experiment ledger as **E23–** .

## Where i07 left us

i07 (E21–E22) showed a *context-free* positional/template generator reproduces the VMS's
low character entropy, block-scale ΔI, and (via block contrast) its weak-but-positive
word-class structure — but across a broad a-priori grid it **never** reproduces the VMS's
morphology connectivity (ED1 ≈ 0.75; the generator overshoots ≈ 0.97), lexical reuse
(TTR ≈ 0.22; generator ≈ 0.59), or frequency slope (Zipf ≈ −0.90; generator ≈ −0.37). All
three misses are **frequency-concentration** failures: an independent bag-of-slots is too
productive and too uniform. E22 named the fix: an added **word-reuse / copying / smaller
effective lexicon / correlated-slot** mechanism.

## The i08 question

**Does bolting a word-reuse (copy-from-recent-context) mechanism onto the positional
generator bring ED1, TTR, and Zipf into the VMS band JOINTLY with entropy + block-ΔI +
weak-positive word-syntax — and does it do so across a broad a-priori parameter basin,
not a fitted point?**

Hypothesis: copying recent tokens (Yule–Simon / self-citation style, rich-get-richer)
concentrates frequency → lowers TTR, steepens Zipf, and shrinks the realised type set so
its edit-distance-1 neighbours are less often realised → lowers ED1 off saturation; and
the copy adjacency injects the mild sequential structure that lifts wc_z from anti-
structure toward the VMS's weak-positive band. If a broad basin covers ≥6/8 axes incl.
the VMS's positive wc_z, the **positional + reuse** class is a *sufficient* account of the
full signature (grade B ceiling — sufficiency of a class, never identification, L7).

## Discipline carried from the i07 refutation (non-negotiable)

1. **A-priori sweep from the start, no fitted point.** E23 is a grid over reuse-rate ×
   generator params with ranges fixed before scoring; the deliverable is the *basin*, not
   a hand-picked config. This is the fix for E21's grid-select-then-call-it-a-priori sin.
2. **Score against the VMS's OWN two-sided bands** (incl. positive wc_z ∈ [1.9, 2.64]),
   never a one-sided threshold a full shuffle also passes.
3. **Report every axis still missed.** A partial win is reported as partial.
4. **Refutation pass before any A/B lock.** Sufficiency of a class ≠ identification (L7);
   the Voynich-tuned self-citation generator is still excluded from counting as evidence.
